# ExViewer 整体设计稿 v2

入口为 `index.html` 的可点击设计台，`overview.html` 并排展示六个画面。所有作品、封面和数值均为本地设计样例，不连接真实站点或账号。

产品界面使用 iOS 语义配色：浅色为白底、系统灰和黑色文字，深色为黑底、系统深灰和白色文字；系统蓝用于选择和操作。设计台自身使用中性灰背景。底栏只有发现、资料库、账号。

发现页搜索栏下方常驻常用组合快捷行。点组合会一次应用站点、关键词、标题范围、包含／任一／排除标签、分类、评分和页数条件并显示匹配结果；“全部／管理”打开完整条件列表，可执行或载入编辑。组合载入后编辑只改变当前搜索草稿，保存时可明确更新原组合或另存新组合。快捷栏与资料库读取同一组本地保存数据。

可体验标签条件、详情标签操作、阅读翻页与缩略图、下载暂停、本机资料、登录管理。设计台可以切换加载、局部失败、浅深色和较大字号；单张重试会保留其余封面。

检查覆盖 `node --check`、本地文件引用和组合完整保存／恢复的代码路径。原生界面尚未按这套设计重写，网络修复单独位于 build 5。
